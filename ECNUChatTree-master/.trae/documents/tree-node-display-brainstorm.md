# 树节点内容显示优化 - 头脑风暴方案

## 一、问题定义

### 1.1 现状
- **节点显示内容**：`DisplayContent => Node.NodeID.ToString()` - 仅显示数字编号
- **节点尺寸**：固定 40x30 像素
- **可用数据**：每个节点有 `UserMessage.Content` 和 `ReplyMessage.Content`

### 1.2 痛点
- 用户只看到数字编号，无法快速定位目标节点
- 需要点击节点才能在右侧面板查看内容
- 树大时，找特定对话非常困难

---

## 二、头脑风暴 - 方案探索

### 方案A：节点内容预览（推荐⭐⭐⭐⭐⭐）

**核心思路**：在节点上显示消息的前N个字符作为预览

**实现方式**：
```
DisplayContent => 消息内容截取前8-12个字符 + "..."
```

**优点**：
- 改动最小，只需修改 `TreeNodeVM.DisplayContent` 属性
- 用户一眼就能看到每个节点的大致内容
- 不改变节点大小

**缺点**：
- 中文和英文显示字符数不同
- 内容太长时截断可能丢失关键信息

**变体方案**：
- A1: 显示用户消息前10字
- A2: 显示AI回复前10字
- A3: 显示"用户消息→AI回复"各5字

---

### 方案B：节点尺寸自适应（推荐⭐⭐⭐⭐）

**核心思路**：根据内容长度动态调整节点宽度

**实现方式**：
```
Width = Math.Max(40, Math.Min(内容长度 * 字体大小, 最大宽度))
```

**优点**：
- 短内容不浪费空间
- 长内容能显示更多

**缺点**：
- 树可能变得不整齐
- 布局算法需要调整

---

### 方案C：悬停提示（Tooltip）（推荐⭐⭐⭐⭐）

**核心思路**：鼠标悬停时显示完整内容

**实现方式**：
```xml
<Border ToolTip="{Binding FullContent}" ToolTipService.InitialShowDelay="500">
```

**优点**：
- 不改变节点外观
- 能查看完整内容
- 实现简单

**缺点**：
- 需要鼠标操作
- 移动端不友好

---

### 方案D：双行显示（推荐⭐⭐⭐）

**核心思路**：节点显示两行内容

**实现方式**：
```
第一行：用户消息预览
第二行：AI回复预览
```

**优点**：
- 信息更丰富
- 清晰区分用户和AI

**缺点**：
- 节点高度增加
- 需要调整布局

---

### 方案E：颜色编码（推荐⭐⭐⭐⭐）

**核心思路**：用颜色区分不同类型的节点

**实现方式**：
```
- 有AI回复的节点：绿色边框
- 无AI回复的节点：灰色边框
- 当前选中节点：蓝色边框
- 包含关键词的节点：黄色背景
```

**优点**：
- 视觉区分明显
- 不增加空间
- 实现简单

**缺点**：
- 不能显示具体内容

---

### 方案F：迷你预览面板（推荐⭐⭐⭐）

**核心思路**：在树旁边添加一个迷你预览面板

**实现方式**：
```
┌─────────────┬──────────┐
│   树可视化    │ 迷你预览  │
│             │ (悬停节点) │
└─────────────┴──────────┘
```

**优点**：
- 不改变树结构
- 显示完整内容

**缺点**：
- 占用屏幕空间
- 需要新增UI组件

---

### 方案G：搜索高亮（推荐⭐⭐⭐⭐）

**核心思路**：添加搜索功能，匹配的节点高亮显示

**实现方式**：
```
搜索框 → 输入关键词 → 匹配节点高亮 + 显示匹配内容
```

**优点**：
- 快速定位目标
- 解决"找"的问题

**缺点**：
- 需要新增UI
- 实现较复杂

---

### 方案H：内容摘要模式（推荐⭐⭐⭐⭐⭐）

**核心思路**：提供两种显示模式切换

**实现方式**：
```
模式1：编号模式（当前）- 节省空间，树整齐
模式2：摘要模式 - 显示内容预览，节点变大
```

**优点**：
- 用户可选择
- 兼顾两种需求

**缺点**：
- 需要模式切换UI

---

## 三、推荐组合方案

### 🏆 最佳方案：A + C + E 组合

**实现内容**：
1. **节点显示用户消息前8个字符**（方案A）
2. **悬停显示完整内容**（方案C）
3. **颜色编码区分状态**（方案E）

**改动清单**：
| 文件 | 改动 | 说明 |
|------|------|------|
| `TreeNodeVM.cs` | 修改 `DisplayContent` | 显示内容预览 |
| `TreeNodeVM.cs` | 新增 `FullContent` 属性 | 用于Tooltip |
| `TreeNodeVM.cs` | 新增 `HasReply` 属性 | 用于颜色编码 |
| `TreeVisualizationView.xaml.cs` | 添加Tooltip绑定 | 悬停显示 |
| `TreeVisualizationView.xaml.cs` | 添加颜色逻辑 | 状态区分 |

**预期效果**：
```
┌──────┐
│ 你好... │  ← 显示用户消息前几个字
├──────┤
│ 悬停显示完整内容：        │
│ 用户: 你好，请帮我...     │
│ AI: 你好！我是...         │
└──────────────────────────┘
```
